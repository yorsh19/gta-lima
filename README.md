# Kalex Urban

Simulador urbano inspirado en Lima, Peru.

## Objetivo
Crear una prueba de concepto viralizable estilo sandbox urbano con:

- Trafico limeño
- Combis
- Mototaxis
- Transporte publico
- Zonas rojas
- Protestas
- Economia informal
- Cultura urbana peruana

## Tecnologias

- Unreal Engine 5
- C++
- Blueprints
- PCG Framework
- World Partition
