# Documentación de Kalex Urban

Este directorio reúne la visión narrativa, el diseño del MVP, la planificación de producción y las fuentes de contexto del proyecto.

## Punto de entrada recomendado

1. [`GDD/GDD_EJECUTIVO_MVP.md`](GDD/GDD_EJECUTIVO_MVP.md): visión ejecutiva y alcance del vertical slice.
2. [`GDD/historia/HISTORIA_PRINCIPAL.md`](GDD/historia/HISTORIA_PRINCIPAL.md): versión resumida de la historia principal.
3. [`ROADMAP/TABLERO_MVP_OPERATIVO.md`](ROADMAP/TABLERO_MVP_OPERATIVO.md): estado operativo y trabajo priorizado.
4. [`ROADMAP/PLAN_DE_ARRANQUE_DESARROLLO.md`](ROADMAP/PLAN_DE_ARRANQUE_DESARROLLO.md): primer plan de implementación.
5. [`REFERENCIAS/CONTEXTO_RECIBIDO/README.md`](REFERENCIAS/CONTEXTO_RECIBIDO/README.md): mapa del contexto consolidado, asuntos abiertos y reglas de uso.

## Estructura

| Carpeta | Contenido |
| --- | --- |
| `GDD/` | Diseño del juego: historia, gameplay, distritos, NPC, misiones, vehículos y transporte. |
| `ROADMAP/` | Roadmap, backlog, tablero operativo, plan de arranque y pruebas. |
| `REFERENCIAS/` | Material fuente, evaluaciones y contexto que orienta decisiones sin convertirlas automáticamente en alcance aprobado. |
| `LORE/` | Espacio reservado para continuidad, cronología y trasfondo. |
| `MARKETING/` | Espacio reservado para audiencia, comunicación y lanzamiento. |
| `PITCH/` | Espacio reservado para materiales de presentación e inversión. |

## Jerarquía documental

- Para ejecutar trabajo, prevalecen el código actual, el tablero operativo y el backlog priorizado.
- Para alcance del MVP, prevalece el GDD ejecutivo.
- Para narrativa, `HISTORIA_PRINCIPAL.md` resume la visión vigente; la fuente expandida conserva matices y asuntos aún no cerrados.
- Los documentos de `REFERENCIAS/CONTEXTO_RECIBIDO/` preservan el contexto original. Cuando contradigan un documento operativo, la contradicción debe resolverse y registrarse antes de implementar.

## Principio rector del MVP

> Un sector pequeño de SJL extremadamente vivo comunica mejor la propuesta que una Lima gigantesca sin gameplay.

El primer objetivo técnico es un vertical slice donde el personaje pueda caminar, interactuar con un vehículo, conducir, chocar y salir; después se agregan sistemas conectados de tráfico, peatones, crimen, policía, economía y presentación.
