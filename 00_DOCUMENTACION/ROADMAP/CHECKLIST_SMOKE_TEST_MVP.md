# Checklist Smoke Test MVP (S1)

## Build y arranque

- El juego inicia sin crash.
- Carga el mapa `L_SJL_Avenida_Graybox`.
- FPS estable en zona inicial.

## Jugador

- Movimiento (WASD) funciona.
- Camara libre sin jitter severo.
- Salto/sprint/interaccion responden correctamente.

## Mision base

- Trigger de inicio de mision funciona.
- Objetivo se actualiza al interactuar con cobrador.
- Completa mision y entrega recompensa.

## Transporte base

- Se puede subir y bajar de combi.
- El pago de pasaje se registra.
- La ruta corta termina sin bloqueo.

## Criterio de salida

- Sin bugs P0 abiertos.
- Maximo 3 bugs P1 abiertos con workaround documentado.
